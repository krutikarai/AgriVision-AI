# AgriVision AI 🌱

## Crop Disease Detection and Intelligent Treatment Assistant

AgriVision AI is an AI-based agricultural assistance system designed to help farmers identify possible crop diseases using images of affected leaves. The system combines Computer Vision, Natural Language Processing (NLP), and Generative AI to provide disease information and conversational treatment guidance.

## Features

- Crop leaf image analysis
- Crop disease detection using Computer Vision
- Natural Language Processing for farmer queries
- Generative AI-based disease explanation
- Step-by-step treatment guidance
- Location-aware agricultural assistance
- Multilingual interaction
- Diagnosis history

## Technologies Used

| Technology | Purpose |
|---|---|
| Python | Core development and AI implementation |
| OpenCV | Crop leaf image preprocessing |
| PyTorch | Deep learning and disease detection model |
| Computer Vision | Crop disease identification |
| NLP | Understanding farmer queries |
| Generative AI | Generating explanations and treatment responses |
| Gemini API | Conversational AI functionality |
| RAG | Retrieving relevant agricultural information |
| FastAPI | Backend API development |
| React | Frontend development |
| PlantVillage Dataset | Crop disease image dataset |

## System Workflow

Farmer uploads a crop leaf image.

The image is preprocessed and passed to the Computer Vision model for disease detection.

The farmer can then ask questions about the detected disease. NLP processes the question, relevant agricultural information is retrieved, and Generative AI generates an understandable response and treatment guidance.

## Project Objective

The main objective of AgriVision AI is to provide farmers with an accessible AI-based system for preliminary crop disease detection and conversational agricultural assistance.

## Future Scope

The system can be extended with weather integration, IoT sensors, drone-based crop monitoring, additional regional languages, voice-based interaction, pest detection, and mobile application support.
